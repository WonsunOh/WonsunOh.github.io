Data Deletion Instructions

App: Foody (My Refrigerator)
Developer: wonsunoh
Last Updated: May 13, 2026
Summary: Foody does not create user accounts and stores all data locally on the user's device only. No user data is stored on any external server. Therefore, users can immediately delete all their data themselves without submitting a separate deletion request.

1. How to Delete Your Data

Method 1: Delete All Data within the App (v1.12.0+ - Recommended)

  1. Launch the Foody app
  2. Tap the menu (⋮) button at the top right of the screen
  3. Select Settings & Management
  4. Expand the Others section
  5. Tap "Delete All Data" (highlighted in red)
  6. Click "Delete" on the first confirmation dialog
  7. Click "Delete" on the second (final) confirmation dialog
  8. After deletion, click "Restart App" → app resets to initial install state

Method 2: Uninstall the App (All versions)

  1. Open Android Settings → Apps
  2. Select Foody (My Refrigerator) from the list
  3. Tap Uninstall

Uninstalling the app immediately and permanently deletes all local data.

2. Data That Will Be Deleted

The following data is immediately and permanently deleted via the steps above:

  • All food item information (name, expiration date, storage location, memo, photo)
  • Storage space information (refrigerator, freezer, pantry, etc.)
  • Notification settings and alarm information
  • Shopping list
  • Recurring purchase items
  • Auto backup files (in app internal storage)
  • Custom units and storage compartment settings
  • All preferences (onboarding state, notification time, backup interval, etc.)

3. Data Retained After Deletion

None. Foody does not store any user data on external servers, so no user data remains after deletion.

4. Data Retention Period

Not applicable. All data is stored only on the user's device and remains there until the user deletes it via the steps above. Since no user data is stored on external servers, no retention period is set.

5. Google AdMob Advertising ID

Ads in the app are served via Google AdMob. The advertising ID (AAID) and related data are managed directly by Google. You may reset your advertising ID or opt out of personalized ads using the following methods:

  • Android Settings → Google → Ads → "Reset advertising ID" or "Opt out of Ads Personalization"
  • Reference: How Google uses information from sites or apps that use our services
