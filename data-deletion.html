데이터 삭제 안내

앱: 우리집 냉장고 (Foody)
개발자: wonsunoh
최종 수정일: 2026년 5월 13일
요약: 푸디는 사용자 계정을 만들지 않고 모든 데이터를 사용자의 기기에만 로컬 저장합니다. 외부 서버에는 어떠한 사용자 데이터도 저장하지 않습니다. 따라서 별도의 삭제 요청 없이 사용자가 직접 즉시 모든 데이터를 삭제하실 수 있습니다.

1. 데이터 삭제 방법

방법 1: 앱 내에서 모든 데이터 삭제 (v1.12.0 이상 - 권장)

  1. 푸디 앱 실행
  2. 화면 오른쪽 상단의 메뉴(⋮) 버튼 탭
  3. 설정 및 관리 항목 선택
  4. 기타 섹션 펼치기
  5. "모든 데이터 삭제" (빨간색) 항목 탭
  6. 1차 확인 다이얼로그에서 "정말 삭제" 클릭
  7. 2차 최종 확인 다이얼로그에서 "정말 삭제" 클릭
  8. 삭제 완료 후 "앱 재시작" 클릭 → 신규 설치 상태로 초기화됨

방법 2: 앱 제거 (모든 버전)

  1. Android 기기 설정 → 앱 진입
  2. 목록에서 우리집 냉장고 (Foody) 선택
  3. 제거(삭제) 버튼 탭

앱 제거 시 모든 로컬 데이터가 즉시 영구 삭제됩니다.

2. 삭제되는 데이터

위 절차를 진행하면 다음 데이터가 즉시 영구 삭제됩니다:

  • 모든 식재료 정보 (이름, 유통기한, 보관 위치, 메모, 사진)
  • 보관 공간 정보 (냉장고, 냉동고, 팬트리 등)
  • 알림 설정 및 알람 정보
  • 쇼핑 목록
  • 정기 구매 항목
  • 자동 백업 파일 (앱 내부 저장소)
  • 사용자 정의 단위 및 보관 칸 설정
  • 온보딩, 알림 시간, 백업 주기 등 모든 환경 설정

3. 보관되는 데이터

없음. 푸디는 외부 서버에 사용자 데이터를 저장하지 않으므로, 삭제 후 보관되는 사용자 데이터는 존재하지 않습니다.

4. 데이터 보관 기간

해당 없음. 모든 데이터는 사용자의 기기에만 저장되며, 사용자가 위 절차로 삭제하기 전까지 기기 내에 유지됩니다. 외부 서버에 저장되는 사용자 데이터가 없으므로 별도의 보관 기간이 설정되어 있지 않습니다.

5. Google AdMob 광고 ID

앱 내 광고는 Google AdMob을 통해 게재되며, 광고 ID(AAID) 및 관련 데이터는 Google이 직접 관리합니다. 다음 방법으로 광고 ID를 재설정하거나 맞춤 광고를 비활성화하실 수 있습니다:

  • Android 기기 설정 → Google → 광고 → "광고 ID 재설정" 또는 "맞춤 광고 선택 해제"
  • 참고: Google이 사이트나 앱에서 정보를 사용하는 방법
